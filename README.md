# Retail Sales Performance Analysis

A Python-based exploratory data analysis of retail transaction data, looking at sales and profit performance across product categories, regions, and customer segments.

## What this project does

- Cleans a transaction-level sales dataset (handles missing values, duplicate rows, and invalid entries)
- Explores sales and profit trends across categories, regions, customer segments, and time
- Investigates how discounting affects profit margin
- Summarizes findings in plain-language insights

## Tools used

- Python
- Pandas, NumPy — data manipulation
- Matplotlib, Seaborn — visualization
- Jupyter Notebook

## Files

- `Retail_Sales_Analysis.ipynb` — the main analysis notebook
- `retail_sales_data.csv` — the dataset used (synthetic, generated for practice purposes)

## Key takeaways

- Electronics and Home & Kitchen lead in total sales
- Discounts above ~15% noticeably reduce average profit margin
- Consumer segment is the largest contributor to sales across all regions

## Note on the dataset

The data in this project is synthetically generated to resemble realistic retail transactions (including some intentional messiness — missing values, duplicates, bad entries) so that the cleaning steps in the notebook have a real purpose. It isn't from a real company.
